# Supervised Machine Learning: Regression and Classification – Machine Learning Specialization

This repository contains my **handwritten notes, lecture summaries, and Python notebooks** from the **Supervised Machine Learning: Regression and Classification** course in the *Machine Learning Specialization* by [DeepLearning.AI](https://www.deeplearning.ai/) and [Stanford University](https://online.stanford.edu/).

This course builds the foundation of **Machine Learning** by teaching the core algorithms and mathematics behind **regression** and **classification** models.

---

## 📘 Course Overview

Key topics covered include:

* What is Machine Learning and how it works
* Linear regression for predictive modeling
* Gradient descent and cost function optimization
* Logistic regression for classification
* Decision boundaries and multi-class classification
* Regularization (L1 & L2) to prevent overfitting
* Model evaluation and performance metrics
* Applications in business and real-world ML systems
